# Calculator

A tiny Python calculator package used as the AutoDev demo repository.

## Functions

- `add(a, b)`
- `subtract(a, b)`
- `multiply(a, b)`
- `divide(a, b)`

## Running tests

```bash
python -m pytest -q
```

## Layout

- `calculator/operations.py` – arithmetic implementation
- `tests/test_operations.py` – pytest suite
